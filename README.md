# Next.js Portfolio

This is a portfolio application built using Next.js, TypeScript, Framer Motion, and Three.js. It showcases various projects and provides information about the developer in an interactive and visually appealing manner.

## Features

- Custom landing page with animations
- 3D scene integration using Three.js
- Reusable components for a consistent UI
- Responsive design with modern layout
- Smooth transitions with Framer Motion

## Technologies Used

- Next.js
- TypeScript
- Framer Motion
- Three.js (or React Three Fiber)
- CSS

## Getting Started

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd nextjs-portfolio
   ```

3. Install dependencies:
   ```
   npm install
   ```

4. Start the development server:
   ```
   npm run dev
   ```
